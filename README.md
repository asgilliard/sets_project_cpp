# BitSet (C++20)

Высокопроизводительная реализация динамического битового множества (`BitSet`) на C++20 для выполнения математических операций над множествами. Проект ориентирован на строгую типобезопасность, отсутствие лишних аллокаций и системную независимость.

## Сборка и запуск

Требуется компилятор с поддержкой C++20 (GCC 10+, Clang 11+, MSVC 2019+) и CMake 3.16+.

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

```

Запуск CLI-приложения:

```bash
./build/bitset_cli

```

## Технические решения и архитектура

### Память и битовые сдвиги

* Битсет хранится в динамическом массиве 64-битных слов `std::uint64_t` (`WORD_SIZE = 64`).
* Расчёт индекса слова (`index >> 6`) и маски бита (`index & 63`) выполнен через побитовые операции, что исключает деление на аппаратном уровне.

### Платформонезависимый парсинг чисел

* Парсинг строк в числа использует `std::stoull` вместо `std::stoul`.
* **Обоснование:** В 64-битных ОС Windows (модель `LLP64`) тип `long` остаётся 32-битным. Использование `std::stoull` гарантирует честные 64 бита на Windows, Linux (`LP64`) и macOS.

### Обработка диапазонов и разделения строк

* Метод `from_string` обрабатывает произвольные разделители (пробелы, запятые, табуляции) и диапазоны значений (`10-15`).
* Запятые нормализуются через `std::replace` перед передачей в `std::istringstream`.
* Объявление переменных `start` и `end` вынесено за пределы `try/catch` блока `stoull`, чтобы валидация логических ошибок диапазона (`start <= end`) происходила независимо от синтаксического парсинга.

### Гарантии исключений и обработка ошибок

* Ошибки обрабатываются через стандартные исключения C++.
* `std::invalid_argument` выбрасывается при синтаксическом браке токенов, наличии букв или перевёрнутых диапазонах (`15-10`).
* `std::out_of_range` пробрасывается из метода `set()` при попытке адресации индекса, превышающего или равного $N$.

### Сериализация в поток

* `operator<<` перегружен как `friend`-функция. Это сохраняет доступ к сырым битовым блокам без нарушения инкапсуляции и формирует вывод в формате математического множества `{0, 1, 4}`.
* Сериализация не создает промежуточных строк в куче (heap) и пишет напрямую в `std::ostream`.

## Интерфейс класса (Public API)

```cpp
namespace sets {

class BitSet {
public:
    explicit BitSet(std::size_t capacity);

    // Базовые операции с элементами
    void set(std::size_t index, bool value);
    [[nodiscard]] bool contains(std::size_t index) const noexcept;

    // Фабричный метод парсинга
    static BitSet from_string(const std::string& input, std::size_t capacity);

    // Модифицирующие битовые операторы
    BitSet& operator&=(const BitSet& other);
    BitSet& operator|=(const BitSet& other);

    // Битовые операторы с возвратом нового значения
    BitSet operator&(const BitSet& other) const;
    BitSet operator|(const BitSet& other) const;
    BitSet operator~() const;

    friend std::ostream& operator<<(std::ostream& os, const BitSet& set);
};

} // namespace sets

```
